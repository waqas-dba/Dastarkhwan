## CoreKit – EF Core & Environment Commands

Visual Studio → Tools → NuGet Package Manager → Package Manager Console

### 1. Set PostgreSQL environment variables

Replace `YOUR_PASSWORD` with your PostgreSQL password.

```
$env:ConnectionStrings__Identity = "Host=127.0.0.1;Port=5432;Database=dasterkhwan_db;Username=postgres;Password=YOUR_PASSWORD"

$env:ConnectionStrings__Tenant = "Host=127.0.0.1;Port=5432;Database=dasterkhwan_db;Username=postgres;Password=YOUR_PASSWORD"

$env:ConnectionStrings__Access = "Host=127.0.0.1;Port=5432;Database=dasterkhwan_db;Username=postgres;Password=YOUR_PASSWORD"
```

### 2. Verify environment variables

```
"Identity: " + [bool]$env:ConnectionStrings__Identity
"Tenant:   " + [bool]$env:ConnectionStrings__Tenant
"Access:   " + [bool]$env:ConnectionStrings__Access
```

### 3. Save environment variables permanently (Windows User)

```
[System.Environment]::SetEnvironmentVariable("ConnectionStrings__Identity", "Host=127.0.0.1;Port=5432;Database=dasterkhwan_db;Username=postgres;Password=YOUR_PASSWORD", "User")

[System.Environment]::SetEnvironmentVariable("ConnectionStrings__Tenant", "Host=127.0.0.1;Port=5432;Database=dasterkhwan_db;Username=postgres;Password=YOUR_PASSWORD", "User")

[System.Environment]::SetEnvironmentVariable("ConnectionStrings__Access", "Host=127.0.0.1;Port=5432;Database=dasterkhwan_db;Username=postgres;Password=YOUR_PASSWORD", "User")
```

Restart Visual Studio or open a new terminal to load permanent variables.

### 4. EF Core – DbContext commands

```
Get-DbContext
```

### 5. List existing migrations

```
Get-Migration -Context IdentityDbContext
Get-Migration -Context TenantDbContext
Get-Migration -Context AccessDbContext
```

### 6. Recreate deleted database

```
Update-Database -Context IdentityDbContext
Update-Database -Context TenantDbContext
Update-Database -Context AccessDbContext
```

### 7. Create new migrations (only after model changes)

```
Add-Migration MigrationName -Context IdentityDbContext -OutputDir Migrations

Add-Migration MigrationName -Context TenantDbContext -OutputDir Migrations

Add-Migration MigrationName -Context AccessDbContext -OutputDir Migrations
```

### 8. Other useful EF commands

| Purpose                 | Command                                                        |
| ----------------------- | -------------------------------------------------------------- |
| Remove latest migration | `Remove-Migration -Context IdentityDbContext`                  |
| Generate SQL script     | `Script-Migration -Context IdentityDbContext`                  |
| Roll back migration     | `Update-Database PreviousMigration -Context IdentityDbContext` |
| Drop database           | `Drop-Database -Context IdentityDbContext`                     |

### 9. Clear environment variables (if required)

Current PowerShell session:

```
Remove-Item Env:ConnectionStrings__Identity
Remove-Item Env:ConnectionStrings__Tenant
Remove-Item Env:ConnectionStrings__Access
```

Permanently remove Windows User variables:

```
[System.Environment]::SetEnvironmentVariable("ConnectionStrings__Identity", $null, "User")
[System.Environment]::SetEnvironmentVariable("ConnectionStrings__Tenant", $null, "User")
[System.Environment]::SetEnvironmentVariable("ConnectionStrings__Access", $null, "User")
```



Recommended

&#x20;For your current database recreation, use sections 1, 2, 5 and 6. No new migration is required.



Security note: Avoid committing database passwords to Git or storing production credentials in source-controlled configuration files.
